# BDRT Holdings — Hero Section

Single-screen, responsive homepage hero concept for the BDRT Holdings design contest.

## Stack
- HTML
- CSS (responsive viewport sizing, layered photography, editorial type)
- Vanilla JavaScript (mobile menu)

## Run locally
Open `index.html` in a browser, or use a local server such as VS Code Live Server.

## Deploy
The repository includes a GitHub Actions workflow in `.github/workflows/static.yml` that deploys the repository to GitHub Pages when changes are pushed to `main`.

## Creative direction
- Obsidian: `#0F0F11`
- Warm Silk Cream: `#F4F1EA`
- Cashmere Grey: `#A1A09A`
- Champagne Dust: `#D4C5B9`
- Gold accent: `#B49A6A`
- Dark emerald accent: `#173F35`
- Headlines: Cormorant Garamond
- Navigation/body: Plus Jakarta Sans

## Photography note
The hero uses an Unsplash stock-photo URL as a design placeholder. Replace it with approved VOXA/VOXA House brand photography or appropriately licensed commercial photography before submitting the final contest entry. The navigation anchors point to sections to be designed later; this repository currently contains the hero section only.
